# Bài tập: Phối màu Newsletter

Gồm 2 phiên bản Bootstrap 5.3.3 với các bảng màu khác nhau, một trang so sánh và hai hình minh họa bảng màu.

Mở `so_sanh.html` để so sánh, hoặc mở từng file `newsletter_version1.html` và `newsletter_version2.html`. Cần có Internet để tải Bootstrap qua CDN.

**Phiên bản 1:** #164E9C, #126E91, #087F8C, #EFF7FB, #17324D.

**Phiên bản 2:** #95402A, #855323, #A34736, #FFF8ED, #402D24.

Hai bảng màu được lựa chọn theo nguyên tắc màu tương đồng. Ảnh `bang_mau_*.png` được tạo để minh họa, **không phải ảnh chụp Adobe Color**. Nếu giáo viên yêu cầu minh chứng thao tác Adobe Color, cần nhập các mã màu tại https://color.adobe.com và chụp ảnh trực tiếp.

Để nộp: tải các file lên repository GitHub công khai rồi dán liên kết repository vào hệ thống học tập.
